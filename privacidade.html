Política de Privacidade

gestor-trafego · Última atualização: 11 de novembro de 2026

Esta política explica como o gestor-trafego, um plugin para o Claude Code que roda no computador do próprio usuário, acessa, usa, guarda e protege os dados das contas do Google que o usuário conecta. Veja também a página inicial do gestor-trafego.

1. Quem somos

O gestor-trafego é uma ferramenta de linha de comando mantida por Lucas Orsolini. Não há site com login, servidor nosso ou banco de dados: o plugin executa na máquina do usuário e fala diretamente com as APIs do Google. Contato: lucas.orsolini@gmail.com.

2. Dados do Google que acessamos

Só com a autorização explícita do usuário, pela tela de consentimento do Google, o gestor-trafego pode acessar:

  • YouTube Data API (escopos youtube e youtube.force-ssl): informações do canal do usuário, lista de vídeos, playlists, legendas e comentários; e, a pedido do usuário, envio e edição de vídeos, miniaturas, legendas, playlists e respostas a comentários.
  • YouTube Analytics API (escopos yt-analytics.readonly e yt-analytics-monetary.readonly): relatórios de desempenho do canal (visualizações, tempo assistido, retenção, origem do tráfego, buscas, dados demográficos agregados e, quando houver, receita estimada).

Não acessamos e-mails, contatos, arquivos do Drive nem qualquer outro dado da conta Google além dos escopos acima.

3. Como usamos os dados

  • Para mostrar ao próprio usuário, no Claude Code, os números e a situação do canal dele.
  • Para executar as ações que o usuário pede no próprio canal (enviar, editar, organizar, responder). Toda ação que altera algo é mostrada antes e só acontece depois da confirmação do usuário.
  • Para gerar recomendações de conteúdo (temas, títulos, horários) a partir desses números.

Não usamos os dados para publicidade, não vendemos dados, não criamos perfis de terceiros e não usamos dados do Google para treinar modelos de inteligência artificial.

4. Onde os dados ficam

  • O token de acesso do Google fica num arquivo de configuração no computador do usuário (o .env do projeto), protegido pelas permissões do sistema. Ele não é enviado a nenhum servidor nosso.
  • Os relatórios que o usuário pede para salvar ficam em arquivos na pasta do próprio projeto, no computador dele.
  • Para responder ao usuário, o Claude Code envia ao modelo de IA da Anthropic o conteúdo necessário daquela conversa, conforme os termos que o próprio usuário aceitou com a Anthropic. O gestor-trafego não envia dados do Google a nenhum outro terceiro.

5. Compartilhamento

Não compartilhamos, vendemos nem transferimos dados de usuários do Google a terceiros. A única exceção é o processamento descrito no item 4, que acontece na conversa do próprio usuário com o Claude Code, por iniciativa dele.

6. Retenção e exclusão

  • Guardamos o token só enquanto o usuário mantiver o canal conectado.
  • Para apagar tudo, o usuário revoga o acesso em myaccount.google.com/permissions (ou security.google.com/settings/security/permissions) e apaga a linha do token no arquivo .env do projeto. Os relatórios salvos são arquivos do próprio usuário e podem ser apagados por ele a qualquer momento.
  • Pedidos de exclusão ou dúvidas: lucas.orsolini@gmail.com.

7. Segurança

As chamadas às APIs do Google usam HTTPS. Credenciais ficam em arquivos com acesso restrito ao usuário do computador e nunca são impressas nem gravadas em repositórios de código.

8. Uso limitado

O uso e a transferência, para qualquer outro aplicativo, de informações recebidas das APIs do Google seguem a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

O gestor-trafego usa os Serviços de API do YouTube e concorda com os Termos de Serviço do YouTube. Consulte também a Política de Privacidade do Google.

9. Mudanças nesta política

Se esta política mudar, a data no topo é atualizada. Mudanças relevantes são informadas na página inicial do gestor-trafego.
